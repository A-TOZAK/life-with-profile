# LiFE with / 外崎顕博 BNI紹介用プロフィールサイト

BNIでの紹介、教育関係者・企業向けの初回共有に使うためのプロフィールサイトです。

## 想定読者

- 学校向けの出前授業・教材・ワークショップを行っている企業
- 教育CSR、SDGs、金融教育、環境教育、キャリア教育に取り組む企業
- 教材会社、教育系商社、ICT支援会社
- 学校や教育委員会に向けて生成AI・DX研修を検討している方
- 地域企業と学校をつなぐ探究学習やキャリア教育に関心がある方

## 主要メッセージ

学校・自治体・企業の思いを、教室で使われる学びに変える。
